# 🚀 Kodeo - Consultoria e Desenvolvimento

Este repositório contém o código-fonte do site institucional da **Kodeo**, uma consultoria especializada em soluções digitais, desenvolvimento de software e estratégia tecnológica.

---

## 🛠️ Tecnologias de Ponta

O projeto foi desenvolvido utilizando tecnologias modernas para garantir alta performance, SEO otimizado e uma experiência de usuário fluida:

* **Next.js 14+** (App Router)
* **TypeScript** (Segurança e tipagem estática)
* **Tailwind CSS** (Estilização responsiva e moderna)
* **Framer Motion** (Animações de interface)
* **Lucide React** (Ícones)

---

## 🏗️ Diferenciais do Projeto

Como este site representa uma consultoria técnica, ele foi construído seguindo padrões rigorosos de engenharia:

* **Arquitetura Limpa:** Separação clara entre componentes de interface e lógica de negócio.
* **Design Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops.
* **Otimização de Performance:** Core Web Vitals otimizados para um carregamento instantâneo.
* **Foco em Conversão:** Estrutura de UI/UX planejada para apresentar serviços de forma clara e objetiva.
